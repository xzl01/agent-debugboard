# 2026-11-04：Tray 四叶片电源状态同步

## 根因与修复

Web logo 的四角按左上、右上、右下、左下分别表示 `5v_out`、`12v_out`、
`vdd_5v`、`20v_out`。Tray 仍沿用三路主电源加右下 legacy Host UART 日志的旧
语义，因而 `vdd_5v=on` 时右下仍可能灰色。原状态 key 和图像缓存没有把三路
主电源画错，错误在第四路的数据源，不是心跳亮暗或 Plasma 未刷新。

本次将 Tray 四角统一为上述四路开关状态，删除 UART 日志依赖。按输出 `name`
匹配，只将明确的 `state=on/off` 作为权威；`value` 不覆盖状态。缺失或未知状态
使探测失败并显示整体 Offline，不冒充四路已知关闭。颜色不表示专用电压测量。
采集提示改为底板细绿边，不再覆盖四叶。保留原 800ms 中心双脉冲、单次边沿唤醒、
固定不可变图标资源及失败退避。

## 验证结果

- 完整 Host tests：**115 项通过**，其中 Tray 44 项；fmt、全 targets clippy
  `-D warnings`、离线 release build 均 exit 0。
- 独立源码复核：四角映射、key/RGBA 唯一性、状态转换、采集时不遮盖电源、
  错误状态不冒充 OFF，均无剩余阻断问题。
- fake API 加真实桌面 SNI：**16 种开关组合 × 采集开/关，32/32 通过**。
  验证实际输出 PNG 的四角像素；覆盖倒序、无关 hub/OTG、`off/value=1`、
  `on/value=null`，没有切换真实板上电源。
- 模拟状态变化至正确 SNI/PNG 的观测延迟：平均 98.3ms，最大 136.1ms；
  这是有限桌面采样，不是延迟上界保证。
- `5v_out+vdd_5v` 开启、采集开/关时，两个心跳相位的四角完全一致；
  同名 PNG hash/mtime 不变，主题路径通知为 0。
- mock Tray exit 0，自有图标目录、socket/server/监视器清理；未清理其他客户端。
