# Radxa Linkr Debugger v0.3.0

v0.3.0 turns Linkr Debugger into a unified hardware-debugging workbench. It
ships the redesigned browser UI, persistent board configuration, a shared Host
and Serial Broker, desktop bundles, richer power and logic analysis, and safer
release/HIL automation.

## Highlights

- Redesigned Web workbench with focused serial, power analysis, logic analyzer,
  automation, hardware control, configuration, and firmware-maintenance flows.
- Unified desktop stack for Windows x64, Linux x64, and macOS Apple Silicon:
  Web UI, board gateway, shared Serial Broker, resident HTTP MCP endpoint,
  CLI/TUI, tray supervisor, UART archive, and per-user installer.
- Shared UART sessions with one OS handle per channel, ordered writes, browser
  and Host bridge modes, and bounded raw/NDJSON archive retention.
- Persistent configuration v1 for selected power, switch, and safe-GPIO state.
  Save applies the selected snapshot immediately and replays it on subsequent
  normal boots; unsupported stored versions are not migrated or replayed.
- Power analysis now separates live capture from startup analysis, preserves
  host-stream evidence, reports dropped/incomplete samples, and exports CSV and
  NDJSON.
- Logic analyzer improvements include Sigrok WebSocket/raw-TCP transports,
  bounded pre-trigger capture, packed deep bursts, UART/I2C/SPI browser decode,
  and explicit capture ownership.
- Firmware-owned ADC3 voltage telemetry, TF write protection, `vdd_5v` routing,
  watchdog state, OTA test-marker evidence, and safer capture/config/flash
  arbitration.
- Workflow automation with nested loops and conditions, execution evidence,
  cleanup semantics, and JSON/CSV/NDJSON reports.

## Install and upgrade

Desktop users should download the archive matching the host platform, extract
it, then run `install.sh` on Linux/macOS or `install.ps1` on Windows. Linux
desktop bundles require GTK 3 and Ayatana AppIndicator 3 runtime libraries.

For the initial install or ROM BOOTSEL recovery, use only
`radxa-linkr-debugger-rp2350.uf2`. This is the combined MCUboot + application
image. Do **not** copy the application-only `zephyr.uf2` to `RPI-RP2`.

For OTA, upload only `radxa-linkr-debugger-rp2350-ota.bin`. The OTA payload is
MCUboot-formatted but unsigned. SHA-256 verifies transfer integrity only.

## Compatibility and security notes

- The compact live ADC WebSocket schema is not the earlier verbose diagnostic
  schema. External consumers must update or use `GET /api/v1/adc/read`.
- Persistent configuration stores one explicit v1 snapshot. There are no named
  profiles, automatic migration, encrypted storage, or automatic rollback.
- Firmware images are not authenticated: there is no signature verification,
  secure boot, authorization, or anti-rollback protection. Treat USB-NCM access
  as trusted physical access.
- High-rate logic-analyzer transports are mutually exclusive: one WebSocket or
  raw-TCP Sigrok session owns capture at a time.

## Release assets

The formal release contains 13 assets: four firmware/debug artifacts, four
platform CLI archives, three unified desktop archives, the Agent skill bundle,
and `SHA256SUMS.txt`. Verify downloaded assets against the checksum file before
installation.
